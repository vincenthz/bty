# bty

`bty` runs programs and coding agents in terminals that stay alive after you leave.

bty is a fork of [herdr-core](https://github.com/herdrdev/herdr-core) (`hc`) with
terminal emulation that comes from Rio's [rio-vt](https://crates.io/crates/rio-vt).

## Install

```
cargo install --path crates/bty
```
